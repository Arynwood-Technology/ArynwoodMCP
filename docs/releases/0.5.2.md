# Arynwood MCP 0.5.2: Community from Grove 0.7.1

**Status: published 2026-10-23.** [GitHub release](https://github.com/Arynwood-Technology/ArynwoodMCP/releases/tag/v0.5.2).

Official packages were built from tag `v0.5.2`, commit `b3fa7fd`. This document's final
validation update follows the tag; the tag and application code were not rewritten. Anyone on
0.4.8 or later sees the update notice; earlier versions need one manual install.

## What's new

**Community screens from Arynwood Grove 0.7.1** (they were 0.4.2). The Community page now has
Grove's side menu and everything Grove added since 0.4.2:

- **Messages** between members, with photos and files, an unread count in the menu that changes
  as messages arrive, and optional notifications.
- **Public chat**, when the Grove opens an IRC room to its members.
- **Lists** with tabs, and a space's **Files**: folders, versions, picture and text previews,
  downloads to your Downloads folder.
- **Webmaster tools**: the Grove's website, the site editor with a live preview, and notes on
  pages. **Visit the site** and **Open in a new tab** open in your browser.
- **Look & feel**, **Grove admin**, **Workspace setup** and the wish lamp.

A Grove's own look colours the Community page only. Peer-to-peer messages are gone, as they
are from Grove. These screens need a Grove on 0.7.1 or later; with an older one, the sections
it doesn't have yet show errors until it is updated.

**html-tools and media load in the desktop app again.** Since 0.4.6 the packaged app refused
its own Client Intake, Flowchart, Terminal Hub and Design Center iframes and media playback
(403 "Cross-site request denied"), because WebKitGTK sends those loads cross-site without an
`Origin`. A short list of read-only paths is allowed now.

Also since 0.5.1: CPU chat fits central's prompt into a small context and answers a bare
greeting without a tool round; Agent Config's **Use tools** setting; the system prompt is kept
when Ollama's `/api/show` fails; Chat's context-size line shows again.

## Validation

- Backend: 841 passed; live evaluation tests excluded. New: the pass-through to Grove 0.7's
  areas, Messages notices, the Public chat socket, streamed files keeping the Grove's
  `sandbox`, previews (served without the sign-in, sandboxed, frameable only by the app, kept
  inside their own address), and the cross-site and `Origin: null` rules.
- Frontend: 280 passed (Grove 0.7.1's own page tests, adapted to Arynwood's paths, and the new
  helpers). Lint: 40 problems, unchanged from the baseline. Type check and build pass.
- Real WebKitGTK 2.52 (the desktop app's engine), with the built app served from
  `tauri://localhost` under the app's content policy, against a throwaway Grove 0.7.1 through
  a scratch backend: every Community section opens without console errors; pictures (logo,
  photos, image files) load; downloads save with their names; the site editor and preview
  panes render the site with its stylesheet and pictures; the unread count changed about a
  second after another member wrote; the layout fits at 1440×900 and 1000×700.
- Upgrade rehearsal: Community 0.3.0 data opened by Grove 0.7.1 on a copy before the owner's
  own local Grove was upgraded.

- A local release-candidate AppImage of the tagged commit passed the frozen-backend smoke
  test, bundled 42 media plugins and played WAV, MP3 and MP4 and recorded in its bundled
  WebKitGTK; nothing private was bundled.
- Tagged [Linux build](https://github.com/Arynwood-Technology/ArynwoodMCP/actions/runs/39894159033)
  and [Windows build](https://github.com/Arynwood-Technology/ArynwoodMCP/actions/runs/39894158770)
  passed, including their frozen-backend smoke gates.
- [Official artifact verification](https://github.com/Arynwood-Technology/ArynwoodMCP/actions/runs/39899722469)
  passed: exact-tag provenance, all three checksums, package versions, AppImage launcher
  permissions, required media plugins, no private configuration/databases/memories in the
  frozen archive, extracted-backend smoke tests, and bundled WebKitGTK WAV/MP3/MP4 playback
  and recording. Uploaded release-asset digests match the verified checksum manifests.

Not run: Public chat against a live IRC room, a Grove on a server from the packaged app (both
community.arynwood.com and roguefest.arynwood.com moved to Grove 0.7.2 at release), and a
clean Windows machine install.
