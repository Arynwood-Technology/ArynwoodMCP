# Arynwood MCP 0.4.9: Community inside the app

**Status: published 2026-10-10.** [GitHub release](https://github.com/Arynwood-Technology/ArynwoodMCP/releases/tag/v0.4.9).

Official packages were built from tag `v0.4.9`, commit `6ae5a99`. This document's final
validation update follows the tag; the tag and application code were not rewritten. Anyone
on 0.4.8 sees the update notice; earlier versions need one manual install.

## What's new

**Community opens inside Arynwood.** The Community page now shows your Grove's spaces:
day planner and calendar, tasks, lists, notes, board, discussion, members and invitations.
A Grove's host also gets its IRC rooms, peer messages and Mail. Before, the page could only
start a Grove and open it in a browser. The screens come from
[Arynwood Grove](https://github.com/Arynwood-Technology/arynwood-community) 0.4.0.

**Choose your Grove.** Use the Grove on this computer (Arynwood can start it), or one on a
server by its `https://` address, for example `https://community.arynwood.com`. Paste an
invitation to a different Grove and Arynwood asks before switching. See
[docs/community.md](../community.md).

**A new look.** Charcoal surfaces with the tree's green-teal light, and larger, brighter
text across the workspace and Design Center. Buttons with white text use a darker green so
they stay readable.

**Fixes.** The Tools and Publish pages no longer crash when the backend is offline.

## How the Grove sign-in works

The desktop window's address (`tauri://localhost`) is a different site from any Grove, and a
Grove's sign-in cookie is restricted to its own site, so the window could never hold it.
Arynwood's backend therefore passes the Community page's requests, live change notices and
the host's IRC/peer-message connections to the Grove you chose, and keeps the sign-in
itself, so you stay signed in after a restart. It contacts only that Grove, only the parts
the Community page uses, never forwards Arynwood's own API key or cookies, and doesn't follow
a Grove's redirects. A Grove on another computer must use `https://`.

Anything on this computer that can use Arynwood's API can also act as the Grove account
signed in there, the same single-owner boundary as the rest of the app
([SECURITY.md](../../SECURITY.md)).
