# Arynwood MCP 0.5.1: managing Community spaces

**Status: published 2026-10-10.** [GitHub release](https://github.com/Arynwood-Technology/ArynwoodMCP/releases/tag/v0.5.1).

Official packages were built from tag `v0.5.1`, commit `545d60a`. This document's final
validation update follows the tag; the tag and application code were not rewritten. Anyone on
0.4.8 or later sees the update notice; earlier versions need one manual install.

## What's new

**Manage a space.** A space's owners get **Manage space** on the Community page:

- Rename the space and give it a topic, which every member sees under its name. Open pages
  show the change within about a second.
- Delete the space for everyone, after typing its name. Members who have it open move to
  another space and are told why.
- Make other members owners, or members again, and remove people. A space always keeps at
  least one owner, so the only owner can neither step down nor leave.

**Assign tasks from the Calendar.** The Calendar's task form has "Assigned to", as Tasks
already did, and each task shows who has it. A private task, which only you can see, can be
assigned only to you.

These need Arynwood Grove 0.4.2 or later. With an older Grove, the new actions say the Grove
needs updating; everything else works as before.

## Validation

  older-Grove message). Lint: 40 problems, unchanged from the baseline.
- Grove 0.4.2: 56 server tests (new: roles and the one-owner rule, deletion removing
  everything, live notices for renames and roles, deletion ending members' live notices, a
  database still usable by 0.4.1 after a rollback) and 38 page tests.

  second person on the Grove's own page: rename and topic, a member made owner, a topic changed
  by the other owner reaching the app live, a task assigned from the Calendar, and deleting the
  space, all passed.
- Through the relay, an older Grove's "Method Not Allowed" reaches the page, which shows the
  update message.
- Backend: 765 passed; 39 live evaluation tests excluded.
- Tagged [Linux build](https://github.com/Arynwood-Technology/ArynwoodMCP/actions/runs/38072718517)
  and [Windows build](https://github.com/Arynwood-Technology/ArynwoodMCP/actions/runs/38072718414)
  passed, including their frozen-backend smoke gates.
- [Official artifact verification](https://github.com/Arynwood-Technology/ArynwoodMCP/actions/runs/38073442208)
  passed: exact-tag provenance, all three checksums, package versions, AppImage launcher
  permissions, required media plugins, no private configuration/databases/memories in the

  and recording. Uploaded release-asset digests match the verified checksum manifests.
