## Changes so far

- **Headless gateway.** `python -m backend.gateway` runs Arynwood MCP as an always-on
  agent with no desktop window. Each outside conversation gets a persistent session,
  reachable over HTTP and a WebSocket (`/api/gateway`). It runs from a source checkout;
  the desktop packages include the same API but don't start the daemon.
- **Trust levels.** Every gateway session is `owner`, `known` or `stranger` (the default).
  Only owner turns see private context or can use tools and web search.
- **Conversational tool loop.** Gateway turns call tools mid-reply until the model decides
  it's done, under the same approval and validation rules as the desktop's tool loop.
- **File memory.** `MEMORY.md` plus dated daily notes, read into owner turns and updated
  after them.
- **IRC adapter.** The gateway joins your own IRC server and trusts services accounts, not
  nicks. Destructive actions are approved with `approve <code>`, from your identified
  account only.
- Codebase tools are served in-process. A tool call in a later code block is no longer
  missed. `find_symbol` finds module-level constants.
- Writer and conversation tuning: optional per-persona output caps, clearer
  evidence-handling and summary instructions.

Full list: `CHANGELOG.md`, `[Unreleased]` (to become `[0.4.6]`).
