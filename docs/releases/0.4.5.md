## Changes

- Windows x64 desktop alpha: unsigned per-user NSIS installer, PowerShell launch/build
  scripts, a packaged-backend smoke test and Windows CI artifacts.
- Native Windows user-data paths (`%LOCALAPPDATA%\arynwood-mcp`, kept across upgrades)
  and browser opening.
- Desktop exit terminates the backend and managed child processes through a Windows
  Job Object.
- Clear errors for the Linux-only optional tool installers and Community startup.
