# Arynwood MCP 0.4.8: Update notices

**Status: published 2026-10-09.** [GitHub release](https://github.com/Arynwood-Technology/ArynwoodMCP/releases/tag/v0.4.8).

Official packages were built from tag `v0.4.8`, commit `3af9867`. This document's final
validation update follows the tag; the tag and application code were not rewritten.

Arynwood now checks for updates automatically at startup and every six hours while open.
A banner appears on every page, including Design Center, when a newer stable release is
available. **View update** opens the official release page in your system browser.
Installation remains manual. Dismiss hides that version across restarts; a later version
shows a new notice.

**Users on 0.4.7 or earlier need to install 0.4.8 manually once** to receive future notices.

Checks contact GitHub's public releases API without credentials, chat, memories or settings.
GitHub receives normal connection metadata, including your IP address. Requests time out
after ten seconds and responses are bounded. Offline, malformed and rate-limited responses
never interrupt the workspace. Draft and prerelease versions are ignored. The public demo
makes no update checks. No download or installer runs automatically.

The existing CPU mode, endpoint support and single-owner security limitations remain;
see [0.4.7](0.4.7.md) and [SECURITY.md](../../SECURITY.md).
